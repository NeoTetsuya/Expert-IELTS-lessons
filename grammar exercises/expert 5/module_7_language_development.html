Expert Grammar Page 188 Reference Guide

Zero Conditional: Form, Meaning & Usage

The zero conditional talks about situations that are generally, universally, or scientifically true, habitual routines, and permanent real-world facts.

0C

Grammar Form

Present Simple in both clauses

1. Basic Structure:

If / When + present simple, present simple.

"If you live in a big city, you have limited space."

2. Inverted Clause Order (No Comma):

Main clause + if / when + condition clause.

"People feel safer if they live in a close community."

3. Modal Verbs & Imperatives in the Main Clause:

We can also use modal verbs (can, should, must) or an imperative:

"If you have elderly neighbours, you should try to help them."

IF/UN

Connectors: If, When, Unless

Real conditions & Exceptions

1. If vs. When:

If and when often mean the same in zero conditional generalisations.

"When / If people visit villages, they like the peace."

2. Unless (= If not / except if):

Unless introduces an exception condition. Followed by affirmative verb:

"Communities don't work well unless they have a central point." (= if they don't have a central point)

3. General Truth vs. Future Specific (First Conditional):

Zero conditional describes what always happens, not a specific future prediction (which uses will).

📌 Summary of Punctuation & Connectors

Clause Order Punctuation Example
Condition first Comma required after if-clause If you live in a city, personal space is limited.
Result first No comma between clauses Personal space is limited if you live in a city.
Unless clause Same comma rule as if I don't carry cash unless I really have to.
