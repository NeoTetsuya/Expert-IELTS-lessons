Unit 9b Glossary Page 145 Reference & Pronunciation Guide

Comprehensive Media & Technology Lexicon

Full reference definitions, phonetic transcriptions, grammatical collocations, and one-click British English pronunciation.

message

verb [T]

To send a short written digital communication to someone, especially using a smartphone app.

Collocation: message friends on WhatsApp

google

verb [T/I]

To search for information on the internet using an online search engine.

Collocation: google a recipe / google for answers

access

verb [T]

To open, view, or use a computer file, database, or restricted website.

Collocation: access secure files / access the network

browse

verb [I/T]

To look through information on web pages casually without a specific search in mind.

Collocation: browse news websites / web browser

crash

verb [I]

When a computer system or software application suddenly stops functioning or shuts down.

Collocation: computer crashes unexpectedly

upgrade

verb [T]

To replace hardware or software with an improved, modern, or more powerful version.

Collocation: upgrade your mobile phone / upgrade software

affect vs. effect

verb vs. noun

Affect (verb): to influence or produce a change in. Effect (noun): the result or outcome.

Rule: technology affects news / environmental effects

hack into

phrasal verb

To gain unauthorized or illegal digital access to another person's computer or server.

Collocation: hack into a database / bank account

back up

phrasal verb

To create an exact duplicate copy of computer data to prevent catastrophic loss.

Collocation: back up essential files to the cloud
